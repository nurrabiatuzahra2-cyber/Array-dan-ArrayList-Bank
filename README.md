# Deskripsi
Project ini merupakan program simulasi ATM sederhana menggunakan bahasa pemrograman Java. Program ini dibuat untuk menerapkan konsep Array dan ArrayList dalam pengelolaan data nasabah dan rekening, serta menyediakan fitur transaksi sederhana.

## Fitur Program
- Menampilkan saldo rekening.
- Melakukan deposit atau penambahan saldo.
- Melakukan withdraw atau penarikan saldo.
- Menambahkan data nasabah.
- Memvalidasi jumlah uang saat transaksi.

## Konsep yang Digunakan
- **Array:** Menyimpan data nasabah dengan kapasitas tertentu.
- **ArrayList:** Menyimpan daftar rekening nasabah.
- **Scanner:** Membaca input pengguna melalui keyboard.
- **Class dan Object:** Mengelompokkan data dan fungsi program.
- **Constructor:** Menginisialisasi objek saat dibuat.
- **Method:** Menjalankan operasi pada rekening dan nasabah.
- **If-else dan switch-case:** Mengatur kondisi transaksi dan pilihan menu.
- **Do-while:** Mengulang menu ATM sampai pengguna memilih keluar.

## Struktur Project
- `Account.java` — Mengelola saldo dan transaksi rekening.
- `Customer.java` — Menyimpan data nasabah dan daftar rekening.
- `Bank.java` — Mengelola data nasabah.
- `Main.java` — Menjalankan program dan menu ATM.

## Teknologi
- Bahasa pemrograman Java
- Visual Studio Code
