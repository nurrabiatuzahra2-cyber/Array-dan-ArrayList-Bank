# Deskripsi
Project ini merupakan program simulasi ATM sederhana menggunakan
bahasa pemrograman Java. Program ini dibuat untuk menerapkan konsep
Array dan ArrayList dalam pengelolaan data customer dan rekening,
serta menyediakan fitur transaksi sederhana.

## Fitur Program
- Menampilkan saldo rekening.
- Melakukan deposit atau penambahan saldo.
- Melakukan withdraw atau penarikan saldo.
- Menambahkan data customer.
- Melihat daftar customer
- Memvalidasi jumlah uang saat transaksi.

## Konsep yang Digunakan
- Array: Menyimpan data customer dengan kapasitas tertentu.
- ArrayList: Menyimpan daftar rekening customer.
- Scanner: Membaca input user melalui keyboard.
- Class dan Object: Mengelompokkan data dan fungsi program.
- Constructor: Menginisialisasi objek saat dibuat.
- Method: Menjalankan operasi pada rekening dan customer.
- If-else dan switch-case: Mengatur kondisi transaksi.
- Do-while: Mengulang menu ATM sampai pengguna memilih keluar.

## Library dan Class yang Digunakan
* **`java.util.Scanner`** — Digunakan untuk membaca input dari pengguna melalui keyboard.
* **`java.util.ArrayList`** — Digunakan untuk menyimpan daftar rekening milik customer secara dinamis.
* **`Customer`** — Class untuk menyimpan nama customer dan daftar rekening yang dimiliki.
* **`Account`** — Class untuk mengelola saldo rekening, deposit, dan withdraw.
* **`Bank`** — Class untuk menyimpan dan mengelola data customer menggunakan Array.
* **`Main`** — Class utama yang menjalankan program dan menampilkan menu ATM.

## Struktur Data yang Digunakan
* **Array (`Customer[]`)** — Menyimpan data customer dengan kapasitas maksimal 10 customer.
* **ArrayList (`ArrayList<Account>`)** — Menyimpan daftar rekening pada setiap customer.
